## 🚀 Cara Menjalankan & Membuka Website

Website ini dibuat berbasis standar web modern murni (*HTML5, Tailwind CSS via CDN, Vanilla JavaScript ES6, FontAwesome, SVG Vector*), sehingga **dapat langsung dibuka tanpa perlu instalasi server atau software tambahan**.

1. Cukup klik ganda (*double click*) file **`index.html`** di Windows Explorer untuk membukanya di browser Google Chrome, Microsoft Edge, Mozilla Firefox, atau Opera.
2. Semua navigasi antar-halaman, formulir pendaftaran, simulasi cetak kartu, dan integrasi WhatsApp berjalan lancar.

## 🌐 Cara Publikasi / Hosting Gratis

Website ini siap di-hosting di berbagai layanan gratis dalam hitungan menit:
- **GitHub Pages:** Unggah semua file ke repositori GitHub, buka *Settings > Pages*, pilih branch `main`, dan website langsung online.
- **Vercel / Netlify:** Cukup seret (*drag-and-drop*) folder `web al ittihad` ke dashboard Netlify Drop (`app.netlify.com/drop`) untuk langsung mendapatkan alamat domain web gratis.
- **Hosting cPanel Madrasah:** Unggah semua file ke folder `public_html` pada panel domain madrasah (misal: `maal-ittihad.sch.id`).
